## C1 — "Cross-vendor GDDR6 swaps are set by strap resistors, not by flashing a different vBIOS"
**Verdict: confirmed (with nuance)** (laptop-2, 2026-11-06, notes/laptop-2.md).
Multiple independent sources: ssateneth2 (r/GPURepair, 2025): "Only way for a person to fix it that isn't under NDA is to replace all X005 with samsung or micron **and adjust the strap** so it boots the correct timings"; khoavd83 (repair specialist, same thread): "You don't need a new bios. Samsung just works even if recognized as Hynix"; GPU Solutions workflow = straps→MATS→boot→stress without reflash [frames]. Nuance 2: vlab t=130309 — a Gigabyte V397 board's stock straps read H-L-H where the V390 schematic says L-H-L: **strap encoding follows the vBIOS/die variant**, so the user must read their actual strap state with a DMM rather than blindly applying the reference table. Cross-flashing other vendors' BIOSes: fails (device ID mismatch / no display) — do not crossflash.

## C2 — "RAMCFG encoding is a GPU property → applies to the Zotac board"
**Verdict: partially-confirmed / corrected** (check worker, notes/check-C2-ramcfg.md).
